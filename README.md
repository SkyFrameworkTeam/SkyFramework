# IslandCore

Núcleo del sistema de islas flotantes para servidores Fabric 1.21.1.
Gestiona el registro de islas, su protección y el teleporte de jugadores
dentro de la dimensión compartida `islandcore:islands`.

## Setup

For setup instructions, please see the [Fabric Documentation page](https://docs.fabricmc.net/develop/getting-started/creating-a-project#setting-up) related to the IDE that you are using.
